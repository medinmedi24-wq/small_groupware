## 발견 및 수정

1. 직원이 기존 휴가를 수정할 때 특별휴가·근속 제한 검증이 빠져 있었다. 서버 검증을 추가하고 직원 수정 화면에서 특별휴가 선택을 제외했다. 관리자 편집 권한은 유지한다.
2. 다른 관리자가 있으면 지정 최종 결재자를 비활성화하거나 일반 직원으로 변경할 수 있었다. 해당 변경을 차단한다. 결재자 교체는 먼저 비공개 설정의 지정 계정을 변경해야 한다.
3. 관리자가 본인 임시 비밀번호를 발급하면 본인 세션이 끊겨 발급 값을 확인하지 못했다. 본인 임시 발급은 차단하고 상단에 비밀번호 변경 링크를 추가했다.
4. 영수증 파일 첨부 후 영수증 보유 표시가 일치하지 않을 수 있었다. 신규 등록과 추가 첨부 모두 파일이 있으면 보유 표시를 저장한다.
5. 모바일 상단 계정 버튼이 글자 단위로 줄바꿈되었다. 계정 정보와 버튼 배치를 조정했다.
