# 검증 기록

> 이 문서는 2026-09-07~08 초기 검증 이력입니다. 최신 SQLite HTTP 결과는 2026-09-15 기준 419개 통과이며 최신 변경의 MySQL 검증·운영 배포는 별도입니다. [개발자 전달 문서](../DEVELOPER-HANDOFF.md)를 우선 확인하세요.

검증일: 2026-09-07 ~ 2026-09-08. 실제 업무 계정·업무 DB가 아닌 격리된 합성 데이터로 검증했습니다.

최신 결재 변경: 사용자가 원본과 PHP 모두의 변경을 허용한 뒤 원본 코드·DB도 함께 수정했습니다. 따라서 아래 54개 파일 보존 기록은 PHP 최초 분리 시점의 결과입니다. 현재 결재는 팀장 → 지정 관리자 지정 관리자이며, 원본 통합 테스트 55개와 빌드, PHP HTTP 70개 및 배포 ZIP 검증을 통과했습니다. 실제 대기 건의 경로 이전은 별도 백업 후 수행했습니다. 자세한 내용은 APPROVAL-CHANGE.md를 참고하세요.

**현재 전달 상태: PHP 소스 및 배포 ZIP 준비 완료.** 2026-09-08 사용자의 복원 조치 후 두 필수 파일을 확인하고 배포 ZIP을 생성했습니다. ZIP을 임시 디렉터리에 풀어 기본 비공개 설정 경로, 초기 설치, 로그인, 페이지 렌더링을 검증했습니다. 초기 설치, bcryptjs 해시 호환, SQLite 날짜 변환, MariaDB 가져오기, 동시 신청, XLSX 열기, phpMyAdmin SQL 가져오기도 통과했습니다. 원본 54개 파일은 SHA-256 대조 결과 변경이 없습니다. 실제 호스팅 배포와 운영 데이터 이전은 수행하지 않았습니다. 에이전트는 보안 예외·격리 복원을 수행하지 않았습니다.

## 실행 환경

- Windows x64, PHP 8.3.33
- SQLite PDO / MariaDB 11.4.5 (별도 localhost 13382 테스트 인스턴스)
- PHP mbstring, fileinfo, zip, pdo_mysql, pdo_sqlite
- Chrome의 실제 PHP 화면, 데스크톱 및 390px 모바일 viewport

HTTP 검사는 관리자 외 직원 관리 차단, CSRF, 저장된 HTML 이스케이프, 기간 중복, 신규 직원 휴가 유형 제한, 3단계 승인, 단계 중복 처리, 팀장·지정 부서의 결재 생략, 반차·취소·반려, 잔여 조정 이력, 카드 권한·상태, 실제 multipart 파일 MIME 검증, 증빙 접근 권한, 관리자 전용 XLSX, 비밀번호 변경·초기화에 따른 세션 무효화 등을 포함합니다.

## 검증 범위의 한계

- 실제 카페24 계정에 업로드하거나 실제 운영 DB를 이전하지 않았습니다.
- 사용 중인 카페24 상품의 PHP 버전·확장·업로드 제한·상위 비공개 디렉터리 접근은 확인 전입니다.
- MySQL 계열 검증은 MariaDB 11.4.5에서 수행했으며 실제 호스팅 DB 버전에서도 최종 확인해야 합니다.
- 다수 직원의 장시간 부하·대량 보고서 성능 검증은 수행하지 않았습니다.
- UI 복원: 원본 style.css/admin.css/icons.css, 로그인, 사이드바 아이콘, 대시보드 관리 패널·월 이동, 직원 목록·팝업, 법인카드 입력 배치·O/X 선택, 휴가 탭, 휴일 패널을 반영했습니다. 데스크톱과 390px 모바일 화면을 확인했습니다. 모든 데이터 상태의 픽셀 단위 일치나 기존 JSON API 호환을 검증한 것은 아닙니다. PHP 폼 제출 후 페이지 이동 방식은 유지합니다.
- 자동 이메일은 원본에도 실행 구현이 없으므로 추가하지 않았습니다.
- 법인카드 이력은 원본처럼 현재 카드 정보에서 표시하며 별도 불변 이벤트 테이블을 추가하지 않았습니다.

## 재현

`tests/http_test.py`는 임시 DB와 임시 PHP 서버를 만들고 종료합니다. PHP 테스트 준비·조회 코드는 Python 검증 스크립트에서 CLI로 전달하므로 공개 웹 루트에 테스트용 PHP 엔드포인트를 만들지 않습니다.

`tests/deployment_test.py`는 빈 DB 초기 설치와 합성 legacy SQLite를 검증합니다. `MNM_DEPLOY_MYSQL_DSN`과 `MNM_SQL_IMPORT_DSN`을 각각 새로운 `mnm_php_test_...` DB로 지정하면 MariaDB 가져오기·동시 신청·SQL 가져오기도 검증합니다. 세 테스트 DSN은 모두 개발 전용 localhost root / 빈 비밀번호 환경용이며 운영 환경에 사용하지 않습니다.
