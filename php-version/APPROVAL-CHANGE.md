# 지정 관리자 최종 결재

관리자 연차 관리의 ‘전체 신청’ 목록에서도 지정 최종 결재자는 관리자 승인 대기 건을 바로 승인·반려할 수 있습니다. 처리 후 직원·부서·기간·상태 검색 조건을 유지하며, 처리 결과가 선택한 상태와 달라 목록에서 사라지면 안내합니다. 승인 확인과 반려 사유 입력은 기존 결재 화면과 동일하며, 다른 관리자나 팀장 승인 대기 건에는 최종 결재 버튼을 표시하지 않습니다.

직원 신청은 팀장 → 지정 관리자, 팀장·이사 신청은 지정 관리자에게 직접 전달합니다. 부서별 팀장 생략 예외는 없습니다. 내부 PENDING_CEO 상태와 ceo 컬럼은 기존 자료 호환을 위해 유지하지만, 결재 권한은 CEO 역할과 무관합니다. 최종 승인은 지정된 사용자 ID와 ADMIN 역할을 모두 만족해야 합니다. 다른 관리자는 현황만 조회할 수 있습니다. 팀장 단계 승인은 해당 부서 팀장만 할 수 있습니다.

2026-09-08 사용자 지시에 따라 원본 React/Node 코드와 PHP 코드를 함께 변경했습니다. 원본 DB와 PHP 미리보기 DB를 각각 백업한 뒤 진행 중인 신청을 새 경로로 이동했습니다. 완료된 과거 결재와 비밀번호는 변경하지 않았습니다. 변경 직후 최종 결재 대기는 원본 2건, PHP 1건입니다. 두 DB는 별도로 운영되며 자동 동기화하지 않습니다.

이전 버전 데이터를 새 PHP DB로 가져온 경우 백업 후 `database/skip-director.sql`을 실행합니다. 승인 완료가 아닌 대기 단계만 이동합니다. 담당자의 실제 사용자 ID는 Git에서 제외된 `config/local.php`의 `final_approver_id`에 지정합니다. 격리된 테스트 또는 별도 설치에서는 `MNM_FINAL_APPROVER_ID` 환경변수로 재정의할 수 있습니다. 설정이 없으면 최종 승인 권한을 부여하지 않습니다. 실제 담당자 이름·아이디를 소스나 공개 문서에 작성하지 않습니다.
