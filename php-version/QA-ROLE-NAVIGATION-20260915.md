# 권한·이동 경로 QA — 2026-09-15

앱 코드는 변경하지 않았다. 별도 SQLite DB와 로컬 서버에서 테스트 계정으로 점검했다. 실제 데이터와 휴대폰 테스트 복사본은 변경하지 않았다.

## 발견 사항

### 1. [P2] 여름휴가 선사용 내역이 있으면 팀장 결재 대기 표시가 사라짐
- 개발팀 직원 신청 1건이 대기 중인 상태에서 팀장 대시보드에 `내 결재 대기 1건`이 표시됨.
- 근속 1년 미만 팀장이 여름휴가 선사용 1일 신청 → 관리자 승인 후 팀장 대시보드에서 대기 표시가 사라짐.
- 팀장 결재 목록에는 여전히 직원 신청 1건과 승인/반려 버튼이 있음. HTTP 및 390×844 브라우저에서 확인.
- 원인: app/ui.php의 `$summer<=0` 조건이 결재 대기 표시 여부까지 제어함.
- 권고: 결재 권한/대기 수와 여름휴가 사용 여부를 분리하고 결재 목록 링크를 제공.

### 2. [P2·사용성] 관리자 법인카드 대기 지표에 이동 경로가 없음
- 관리자 대시보드의 휴가 진행 카드는 클릭하면 `admin-leaves&status=IN_PROGRESS`로 이동하며 필터와 2건 목록이 일치함.
- 같은 화면의 법인카드 `검토 대기 1건`, `승인 완료 0건`은 링크가 없는 일반 카드. 바로가기 화살표와 해당 영역의 관리 목록 링크도 없음.
- 확인/처리를 위해 사이드 메뉴로 다시 이동해야 함. app/ui.php의 법인카드 dashboardMetric 호출은 href를 전달하지 않음.
- 권고: 조회 중인 월과 해당 상태를 유지해 관리 목록으로 연결.

### 3. [P3] 관리자 직원 휴가 수정 팝업 제목이 ‘내 연차’
- 관리자 → 휴가 결재 진행 카드 → 직원 staff 신청 수정.
- 팝업 제목은 `내 연차`, 본문 신청자는 `staff · 개발팀`으로 표시됨. 다른 직원 신청을 수정하는 화면을 본인 신청처럼 소개함.
- 390×844 브라우저에서 재현. 권고: 관리자 타인 신청은 `직원 연차 수정` 또는 신청자 이름을 포함한 제목 사용.

## 정상 확인
- 직원·팀장 모두 직원 관리, 연차 관리, 근태 관리, 카드 관리, 회사 휴일, 관리자 이력 직접 접근 HTTP 403.
- 팀장의 다른 팀 신청 승인 POST 및 수정 화면 접근 HTTP 403. 결재 목록에는 같은 팀 직원만 표시.
- 직원이 다른 직원 신청 ID로 개인 이력을 조회하면 HTTP 200 빈 결과이며 타인 신청 사유는 노출되지 않음.
- 일반 직원 메뉴에는 관리자/팀장 메뉴가 없음. 팀장 메뉴에는 팀장 결재가 표시됨.
- 관리자 휴가 진행 카드의 상태 필터 및 결과 건수가 일치함.
- 모바일 관리자 수정 저장 후 원래 `IN_PROGRESS` 필터와 `listPage=1` 목록으로 복귀함.
- 모바일 팀장 메뉴 열기/이동이 동작하며 확인한 목록 화면에서 가로 넘침은 보이지 않음.
