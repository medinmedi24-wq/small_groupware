# M&M WORKS — 기능·사용 설명

기준일: 2026-09-15

직원이 출퇴근과 휴가·법인카드 사용 내역을 기록하고, 팀장과 관리자가 신청을 처리하는 사내 그룹웨어입니다. 현재 사용 소스는 `php-version/`이며 PC와 휴대폰 브라우저에서 사용합니다.

이 문서는 사용자·운영 담당자용입니다. 실행 환경, 코드 구조, 데이터 이전 및 개발 작업은 [개발자 전달 문서](DEVELOPER-HANDOFF.md)를 참고하세요.

## 현재 상태

- 로컬 PHP 버전으로 개발·QA를 진행했습니다. 실제 운영 호스팅 배포 완료 상태는 아닙니다.
- 휴대폰 테스트는 업무 데이터와 분리한 테스트 서버에 임시 HTTPS 주소를 연결해 진행했습니다. 임시 주소는 종료되거나 바뀔 수 있습니다.
- 최근 QA에서 확인한 연차 변경 충돌, 휴일 변경 보호, 대시보드 이동 및 수정 팝업 제목을 수정했습니다.
- 최신 전체 HTTP 회귀 테스트는 격리 SQLite에서 419개 통과했습니다. 모든 실기기·운영 환경 검증이 끝났다는 뜻은 아닙니다.

## 역할별 업무

| 역할 | 사용하는 기능 |
| --- | --- |
| 일반 직원 | 본인 출퇴근, 누락·정정 신청, 휴가 신청·조회, 법인카드 사용·증빙 등록 |
| 팀장 | 개인 기능 + 같은 부서 직원의 휴가 승인·반려, 본인이 처리한 신청의 이후 상태 확인 |
| 관리자 | 직원 계정·권한·연차 관리, 근태 정정 처리, 법인카드 검토, 회사 휴일 관리, 보고서 |
| 지정 최종 관리자 | 관리자 기능 + 휴가 최종 승인·반려. 모든 관리자가 최종 승인할 수 있는 것은 아닙니다. |

## 출퇴근 기록

### PC와 휴대폰

- **PC:** 오늘의 출근·퇴근 시각을 직접 입력하고 확인 후 저장합니다.
- **휴대폰:** 위치 권한을 허용하면 GPS 확인 후 서버의 현재 시각으로 저장합니다.
- PC와 휴대폰은 **같은 서버·같은 직원 계정**을 사용해야 같은 기록을 확인할 수 있습니다. 서로 다른 로컬·테스트 서버의 데이터는 합쳐지지 않습니다.
- 대시보드·출퇴근 기록·관리자 근태 화면은 보이는 동안 약 10초마다 변경 여부를 확인합니다. 폼 입력·팝업·GPS 확인 중에는 자동 갱신을 보류하므로 필요하면 입력을 마친 뒤 새로고침합니다.

### 회사 근무와 외근·출장

- 일반 모바일 출퇴근은 현재 설정된 송도 AIT센터 반경 150m 기준입니다. GPS 오차까지 반경 안에 들어와야 하며 허용 오차는 최대 100m입니다.
- 회사 밖에서 출퇴근할 때는 **출장 출퇴근**을 선택하고 출장지·사유를 입력합니다. 위치 확인은 동일하게 필요합니다.
- 위치 권한 거부, 오래된 위치, 큰 오차, 회사 경계에 걸친 위치에서는 다시 확인해야 합니다.
- 브라우저 GPS는 좌표의 진위까지 보장하는 장치가 아니며, 이동 경로를 계속 추적하지 않습니다.

### 누락·정정

저장된 출퇴근 기록은 직원이 바로 덮어쓰지 않습니다. 누락·정정 신청을 제출하고 관리자가 승인하면 반영됩니다. 대기 중인 본인 신청은 수정·취소할 수 있습니다. 관리자는 본인 정정 신청을 처리할 수 없습니다.

자정을 넘긴 퇴근은 원래 근무일에 연결합니다. 24시간을 넘긴 미퇴근 기록은 정정 신청으로 처리합니다. 승인된 종일 휴가에는 일반 출근을 차단합니다. 자동 급여·야근 계산은 제공하지 않습니다.

## 휴가 신청과 결재

1. 직원이 종류·기간·사유를 입력하면 예상 차감과 신청 후 가능 일수를 확인할 수 있습니다.
2. 일반 직원·대리·과장 신청은 **팀장 → 지정 관리자** 순서로 처리합니다.
3. 팀장·이사·부장 신청은 지정 관리자에게 직접 전달됩니다.
4. 직원은 신청 내역과 이력에서 결과를 확인합니다. 팀장은 ‘내가 처리한 신청’에서 이후 상태를 확인합니다.

- 연차·반차·병가·공가·여름휴가 선사용 등을 지원합니다. 특별휴가는 관리자 처리 대상입니다.
- 주말·등록된 회사 휴일을 제외하고 계산하며 반차는 0.5일입니다. 자동 발생 연차는 입사일을 기준으로 계산하며 관리자가 수동 연차·잔여 조정을 관리할 수 있습니다.
- 본인 수정·취소는 최초 결재 전까지만 가능합니다. 팀장 승인 후에는 관리자에게 문의합니다.
- 승인된 휴가는 관리자가 사유를 남기고 취소할 수 있습니다. 연차 차감 대상이면 해당 차감이 복구됩니다.
- 검토 중 다른 사람이 기간·일수·사유 등을 변경하면 오래된 화면의 승인·수정·취소가 차단됩니다. 새로고침 후 최신 내용을 확인하세요.
- 대기·승인 휴가의 일수에 영향을 주는 회사 휴일 추가·삭제는 차단됩니다. 영향받는 신청을 확인하고 해당 날짜를 제외하도록 수정하거나 취소한 뒤 다시 진행합니다. 기존 차감 일수를 자동으로 바꾸지는 않습니다.

## 법인카드

사용일, 사용처, 상세 사용 내역, 금액과 증빙 정보를 등록합니다. JPEG·PNG·WebP·PDF 증빙은 최대 10MiB까지 지원합니다.

- 직원은 본인 검토 대기 내역을 수정·취소하고 증빙을 첨부할 수 있습니다.
- 관리자는 승인하거나 사유를 입력해 반려합니다.
- 검토 후 내용이나 증빙이 바뀌면 오래된 승인·수정 요청을 차단합니다.
- 정상적으로 증빙을 교체하면 이전 파일을 정리합니다. 과거 누적 파일을 일괄 삭제한 상태는 아닙니다.
- 별도의 카드 내역 Excel/CSV 내보내기는 현재 제공하지 않습니다.

## 대시보드와 보고서

- 관리자 휴가 지표를 누르면 해당 상태의 관리 목록으로 이동합니다.
- 팀장·지정 관리자의 ‘내 결재 대기 →’는 해당 결재 목록으로 이동합니다. 여름휴가 사용 여부와 관계없이 표시됩니다.
- 관리자 법인카드 ‘검토 대기·승인 완료’ 카드는 선택한 월과 상태를 유지해 목록으로 이동합니다.
- 관리자가 다른 직원 휴가를 수정하면 팝업 제목은 ‘직원 연차 수정’입니다.
- 연도별 휴가 현황 XLSX와 관리자 월별 근태 CSV를 제공합니다. 근태 월별 내역·CSV에는 실제 출근 기록이 있는 날짜가 포함됩니다.

## 로컬에서 실행하기

현재 PC에서는 프로젝트 루트의 `start-php.cmd`를 실행한 뒤 [로컬 화면](http://127.0.0.1:4082)에 접속합니다. 해당 주소는 그 PC에서만 사용할 수 있습니다. 휴대폰은 별도 HTTPS 접속 주소가 필요합니다.

현재 업무 DB와 테스트 DB는 별개입니다. 테스트 DB를 업무 DB로 덮어쓰지 마세요. 백업·이전은 DB와 증빙을 함께 다뤄야 합니다.

## 운영 전 남은 확인

- 실제 휴대폰에서 직원 신청 → 팀장 처리 → 관리자 처리 → PC·휴대폰 결과 일치까지 전체 흐름 확인
- 운영 주소·HTTPS·호스팅 환경 확정
- **근태 데이터를 포함한 전체 DB 이전 방법 준비 및 검증**
- DB·증빙 백업과 복구 절차 마련
- 운영 MySQL/MariaDB에서 최신 변경과 동시 처리 검증

현재 연동은 PHP 웹 화면 기준입니다. 전달된 meditime 네이티브 앱 연결, Notion 연결, 자동 이메일 보고서 발송은 현재 구현 범위에 포함되지 않습니다.
